# Text Extractor

Projeto de estudo desenvolvido em Java + Spring Boot.

## Objetivo

Criar uma aplicação capaz de extrair texto de diferentes formatos de documentos.

## Objetivos futuros

- [ ] Suporte a arquivos TXT
- [ ] Suporte a PDF
- [ ] Suporte a DOCX
- [ ] OCR para imagens
- [ ] Preservação de layout
- [ ] Conversão entre formatos
